⚙️ Impostazioni Ollama
Usare l'Ollama installato sul computer

Di default il Coach usa l'Ollama avviato da Docker, all'indirizzo /ollama: non serve configurare nulla. Al primo avvio Docker scarica i modelli (circa 5 GB); l'avanzamento è in docker compose logs -f ollama-pull.

Per usare invece un Ollama installato sul computer (per esempio per sfruttare la GPU del Mac), nel file .env togli il # da queste due righe ed esegui di nuovo docker compose up -d:

OLLAMA_CONTAINERS=0
OLLAMA_URL=http://host.docker.internal:11434

Scarica i modelli sul computer con ollama pull qwen2.5:7b e ollama pull nomic-embed-text, e lascia l'endpoint a /ollama. Se il Ping non risponde, avvia Ollama in ascolto su tutte le interfacce: OLLAMA_HOST=0.0.0.0 ollama serve.
